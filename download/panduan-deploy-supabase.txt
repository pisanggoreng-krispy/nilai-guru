--------------------------------------------------------------------------------
LANGKAH 1: JALANKAN SQL DI SUPABASE (JIKA BELUM)
--------------------------------------------------------------------------------
1. Buka https://supabase.com dan login
2. Pilih project Anda
3. Klik SQL Editor di menu kiri
4. Klik "New query"
5. Copy-paste seluruh SQL dari file "sql-schema.txt" yang disediakan
6. Klik "Run"

LANGKAH 3: PUSH KE GITHUB
--------------------------------------------------------------------------------
Buka CMD/PowerShell di folder project, jalankan:

--------------------------------------------------------------------------------
                         TROUBLESHOOTING
--------------------------------------------------------------------------------

❌ Error: "Failed to connect to Supabase"
✅ Solusi: 
   - Periksa SUPABASE_URL dan SUPABASE_ANON_KEY di Environment Variables
   - Pastikan tidak ada spasi di awal/akhir value

❌ Error: "relation "users" does not exist"
✅ Solusi: 
   - SQL belum dijalankan di Supabase
   - Jalankan ulang SQL dari file sql-schema.txt

❌ Login gagal
✅ Solusi: 
   - Pastikan tabel users sudah ada data
   - Jalankan ulang INSERT INTO users di SQL

❌ Error: "JWT_SECRET is not defined"
✅ Solusi: 
   - Tambahkan JWT_SECRET di Environment Variables Vercel
